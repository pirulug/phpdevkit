# PHPDevKit

Este repositorio contiene varios proyectos y utilidades desarrollados en PHP para facilitar tareas comunes de desarrollo. A continuación se explica brevemente cada uno de los proyectos incluidos:

## Proyectos

### 1. Extraer SQL de una Base de Datos
Herramienta para extraer el esquema y los datos de una base de datos en formato SQL. Útil para respaldos o migraciones.
[Ver más](estraer-sql)

### 2. Generador de CRUD
Aplicación que genera automáticamente las operaciones básicas (Crear, Leer, Actualizar, Eliminar) para una tabla de base de datos.
[Ver más](generador-crud)

### 3. Validador de Datos
Librería para validar datos de formularios, como correos electrónicos, números, fechas, etc.
[Ver más](validador-datos)

### 4. Conversor de CSV a SQL
Convierte archivos CSV en sentencias SQL para importar datos fácilmente a una base de datos.
[Ver más](csv-a-sql)

## Cómo usar

Cada proyecto tiene su propia carpeta y README con instrucciones específicas. Revisa cada uno para más detalles sobre instalación y uso.
